# Project instructions

- Keep implementation, test and build code JavaScript/TypeScript only.
- Do not invoke Codex CLI/API or create delegated Codex development tasks.
- Implement independently. Never commit captured private runtime, HAR, original reference screenshots, credentials, or third-party code with unknown redistribution rights.
- `scripts/generate-schema.mjs` owns schema/type/standalone-validator generation. Run `npm run check` and applicable browser tests before reporting completion.
- Declare unsupported capabilities. Do not equate schema recognition with rendering, or catalog entries with verified functionality.
- No npm publication, formal release, deployment, or permission changes without explicit authorization.
