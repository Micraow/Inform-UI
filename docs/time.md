# 本地时钟、秒表与倒计时

这是62节点开发源码中的 `time` 领域候选。公开推荐的6797固定CDN仍为52节点，不能接收这些新节点；本批真实浏览器与同版本CDN验收完成前，不增加已验组件计数。所有数据、样式和交互都是项目原创实现。

## 三种明确的时间来源

`clock` 必填 `mode` 和有效 `timezone`。`mode:"snapshot"` 必须带有时区偏移的有效ISO `at`；它显示调用方提供的固定时刻，不随设备时钟推进。`mode:"live"` 禁止 `at`，读取当前设备时间；组件不联网校时。两种模式都显示所选时区的日期和时区标识，可选 `hourCycle:"h12"|"h23"`（默认h23）、`seconds`（默认true）。

```json
{"type":"clock","mode":"snapshot","timezone":"Asia/Shanghai","at":"2026-10-09T16:00:00Z","title":"固定时刻"}
```

`stopwatch` 从暂停状态开始，可选 `elapsedMs`（0–604800000的整数，默认0）和 `laps`（默认true）。支持开始、暂停、继续、重置和分圈。重置恢复所给初始用时并暂停，同时清空本实例分圈；最多保留100圈，达到上限后禁止继续记录，不丢弃旧记录。首圈分段只计算本次开始后的时间，累计时间仍含初始用时。

`timer` 必填整数 `durationMs`，范围1–604800000（七天）。初始暂停；支持开始、暂停、继续、重置以及完成后重新开始。剩余时间到0时停止计时，独立状态区域播报一次完成；不会显示负值。倒计时的正数不足百分之一秒时向上显示为0.01秒，秒表显示向下取百分之一秒；原始毫秒仍保留在实际元素上。

```json
{"type":"timer","durationMs":90000,"title":"90秒本地练习"}
```

三者均可提供普通 `id` 和1–200字的 `title`。时区、日期、单位边界和多余字段都经过统一校验；不能加入脚本、回调、通知URL、声音或自动启动参数。

## 交互和边界

秒表和倒计时以所属窗口的单调 `performance.now()` 基线计算经过时间，不靠回调次数累加；延后的回调会追赶到正确时间。它们是页内控件，不是操作系统闹钟：设备休眠可能影响计时，关闭页面后不会提醒，不提供后台服务或持久化。

按钮采用原生键盘交互。当前焦点按钮因开始、暂停、完成或上限变为禁用时，焦点转到相应可用动作；正常tick不移动外部焦点。数字区域不逐帧播报，用户操作与完成状态单独播报。文字跟随最近宿主的中/英文语言设置。

无关 `setState()` 保留本地计时、分圈和焦点；`update()` 重建新内容，`dispose()` 取消定时器和事件监听。多个实例独立。包含实时clock的HTML编译仍是确定性的，当前时间只在浏览器mount后读取。

完整原创[示例JSON](../examples/time.json)。`cdn/schema/time.schema.json` 是包含base布局的完整Document闭包；`cdn/schema/nodes/time.schema.json` 仅供字段查询，不能代替Document校验。当前源码测试与将来的固定CDN证据须分开看待。
