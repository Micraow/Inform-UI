# Use Inform UI in a browser

Load the library, provide an iui/1 JSON document, and mount it into your page. No OpenAI account or service is needed.

## Minimal page

Save this as an HTML file or serve it from your own site:

```html
<!doctype html>
<html lang="en">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Micraow/Inform-UI@17f4ca2fed7c5cee5a2165e5a0fba190263d126a/cdn/iui.css"
  integrity="sha384-wIJgNTUCIdXWkaiCt+Gga9XZ/4xoZWtHxm3aHCPBTA4NPy3RUFKHZ+4dxD4+hzld" crossorigin="anonymous">
<main id="answer"></main>
<script src="https://cdn.jsdelivr.net/gh/Micraow/Inform-UI@17f4ca2fed7c5cee5a2165e5a0fba190263d126a/cdn/iui.global.min.js"
  integrity="sha384-2MoqZxB7GeFGWnRxVr5pn9esR5F3wVAU+6A6rv2CrgyYeKNhj1NVG0e/nIk4KQPI" crossorigin="anonymous"></script>
<script>
const spec = {
  version: "iui/1",
  state: { quantity: 2 },
  body: [
    { type: "slider", label: "Quantity", bind: "quantity", min: 1, max: 10, step: 1 },
    { type: "metric", label: "Selected", value: { $: "quantity" } }
  ]
};
const result = IUI.validateDocument(spec);
if (!result.ok) throw new Error(result.issues.map(i => i.message).join("\n"));
const view = IUI.mount(document.querySelector("#answer"), result.document, { styles: false });
// Call view.dispose() when removing the view.
</script>
</html>
```

The external stylesheet now includes GCS, ROX, qSOFA and Questionnaire styles. KaTeX fonts resolve relative to the fixed stylesheet URL. An offline deployment must copy all files listed in the integrity manifest and retain their relative paths.

## Verification

The build passed the complete local check: 4,116 tests plus generation, builds, TypeScript, resource-queue checks, consumer types and the source boundary check. A separate build reproduced all 52 CDN payloads byte-for-byte. All 52 published payloads and the integrity manifest were fetched from the public Git commit and independently rehashed.

The two JavaScript bundles, their maps, CSS, full schema and license files were also fetched through the fixed CDN URLs and matched their expected bytes. Other HTTP paths and public-network browser interaction remain unverified; the verification browser could not connect to the CDN.

Six local browser groups covered external styles with SRI, questionnaire cancellation and asynchronous retirement, form focus/reset, and popover resource disposal. Fixed CDN HTTP verification and the representative public-network browser checks are recorded separately in the current lock; do not infer full browser coverage from HTTP availability.

Historical fixed-version links and their verification records remain available in [the earlier CDN guide](cdn.md). This repository update does not publish an npm package.
